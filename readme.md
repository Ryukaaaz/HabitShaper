# Habit-Shapper
a lightweight, web-based application that helps users build
positive habits and break negative ones through daily tracking and streak management.

this application built with:

## Tech Stack

Frontend:
- React
- TypeScript
- TailwindCSS
- Framer Motion

Backend:
- Express
- JWT
- MySQL2

Infrastructure:
- Docker
- Docker Compose



# Features

- JWT Authentication
- Build & Break Habits
- Habit Streak Tracking
- Weekly Completion Tracking
- Goal Management

# Run Locally with Docker

Requirements:
- Docker
- Docker Compose

### 1. Clone repository

```bash
git clone https://github.com/Ryukaaaz/HabitShaper
```

### 2. Setup environment

```bash
change directory to HabitShaper
example C:\Users\micha> cd HabitShaper
```

### 3. Start application

```bash
docker compose up --build
```
